
# Multi-Agent AI System for Disaster Management

## Overview
A disaster-response simulation that explores how multiple rescue robots can coordinate to navigate hazardous environments and assist victims.

## Key Features
- Multi-robot rescue simulation with one scout robot and two rescue robots
- A* path planning for navigation through obstacles
- Victim prioritization based on urgency
- Rubble and aftershock risk considerations in route planning

## Technologies
- Python
- A* Search
- Multi-agent systems
- Path planning and simulation

## My Contribution
