

# Multi-Agent Disaster Response Simulation

A Python-based simulation of a disaster-response system in which aerial drones and ground robots coordinate to locate victims, navigate obstacles, clear debris, and carry out rescue tasks.

## Features

- Multi-agent simulation with drones, scout robots, debris-clearer robots, and rescue robots
- A* path planning on a 100 × 100 grid
- Obstacle avoidance and dynamic path planning
- Simulated aftershocks with navigation penalties
- Victim detection, assessment, prioritization, and rescue workflows
- Interactive Matplotlib visualization of the disaster zone and mission progress

## Technologies

- Python
- NumPy
- Matplotlib
- A* Search
- Multi-agent systems and path planning

## Run the Project

Install the required libraries:

```bash
pip install numpy matplotlib
```

Run the simulation:

```bash
python disaster_sim.py
```

## Project Goal

Explore how multiple autonomous agents can coordinate their actions and adapt their navigation decisions in a changing disaster environment.
